# 2048AiGame: план работ

Описание - в `spec.md`. Задачи идут по порядку, каждая заканчивается зелёными тестами и коммитом. Образец устройства - `..\TicTacToeAi`.

## Этап 1. Игра и ИИ

1. **Каркас.** `git init`, LICENSE (MIT), README EN/RU, requirements, pytest, CI для Gitea и GitHub.
2. **Правила** `core/game2048.py`.
   - Поле - 64-битное число: 16 клеток по 4 бита. Сдвиги строк берутся из готовых таблиц, так быстрее.
   - Тесты:
     - каждая плитка сливается не больше одного раза за ход;
     - появление плиток: 90 на 10 на большой выборке;
     - конец игры;
     - сравнение с медленной простой реализацией на случайных партиях;
     - мутационная проверка.
3. **N-tuple сеть и обучение TD** - `nn/ntuple.py`, `train/td.py`:
   - симметрии;
   - снимки и продолжение с места;
   - журнал;
   - ограничение потоков.

   Тест: короткое обучение заметно поднимает средний счёт над случайной игрой.
4. **Expectimax** на 1-3 хода с лимитом времени. Тест: на собранных позициях выбирает очевидно лучший ход.
5. **Полное обучение, уровни и паспорт** - проверки из spec §4. Сначала замер скорости и прогноз времени, потом полный прогон.

## Этап 2. Окно (PySide6)

6. **Поле и анимации**, клавиатура и мышь (свайп), отмена хода.
7. **Режимы игры:**
   - «Играет ИИ»: пауза, скорость, шаг. ИИ считает ход в отдельном потоке;
   - «Соревнование»: одно зерно для двух полей;
   - «Подсказка» и «Мысли ИИ».
8. **Оформление:**
   - статистика;
   - темы;
   - RU/EN;
   - window-state;
   - дополнительные размеры поля.
9. **Тесты окна** offscreen, снимки для README.
