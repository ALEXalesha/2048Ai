# 2048Ai

Игра 2048 и ИИ, который сам научился в неё играть. Windows, Python, PySide6, numpy.

*Работа идёт.* English: [README.md](README.md).

## Как устроен ИИ

**N-tuple сеть**, обученная **методом временных разностей (TD) на позициях после хода**
(Szubert и Jaśkowski; Yeh, Matsuzaki и другие): доска после хода, до появления новой
плитки, оценивается суммой таблиц по нескольким группам из 6 клеток, во всех 8 симметриях
доски. Сеть учится, только играя против случайности. Сильный уровень добавляет поиск
**expectimax**: перебор всех пустых клеток и обеих возможных новых плиток.

## Запуск из исходников

```
pip install -r requirements.txt
python main.py
```

Проверки: `pip install -r requirements-dev.txt` и `python -m pytest -q`.
